|---|---|---|
| 1 | 프로젝트 세팅 (Next.js, Supabase 로컬), 스키마 마이그레이션, 작가 가입/로그인 | 완료 |
| 2 | 갤러리 생성·목록·설정 (기본 셀렉 장수, 가격, 만료일, 비밀번호) | 완료 |
| 3 | 원본 다중 업로드 (R2 presigned URL), 비동기 미리보기·워터마크 생성 | 완료 |

## 외부 계정 (해당 단계에서 사용자가 직접 생성)

- Cloudflare R2: 3단계
- 토스페이먼츠 (작가별 키, 개발용 테스트 키): 6단계
- Resend: 8단계
- Supabase 클라우드, Vercel: 9단계

## 배포할 때 확인할 것

- **R2 CORS**: 버킷에 사이트 도메인의 `PUT`, `GET`을 허용한다. 허용 헤더는 `content-type`이다. 로컬 Supabase는 모든 출처를 허용해서 로컬에서는 드러나지 않는다.
- **R2 수명 주기 규칙**: `trash/` 경로의 객체를 7일 뒤 삭제한다.
- **워터마크 글꼴**: 서버에 글꼴이 없으면 "PREVIEW" 글자가 빠지고 띠만 보일 수 있다. 배포 후 미리보기 한 장을 직접 확인한다.
- **이미지 처리**: 지금은 업로드가 끝난 직후 같은 서버에서 `after()`로 처리한다. 대량 업로드 때 함수 실행 시간이 부족하면 작업 큐(Inngest 등)로 옮긴다.
- **공유 비밀번호 요청 제한**: 지금은 틀릴 때마다 0.8초 지연만 둔다. 짧은 비밀번호(4자)는 무차별 대입에 약하므로, 배포 시 IP 기준 요청 제한(Vercel WAF 또는 Upstash Ratelimit)을 추가한다.
- **`GALLERY_ACCESS_SECRET`**: 운영 환경에 새 랜덤 값을 설정한다. 이 값을 바꾸면 고객들이 비밀번호를 다시 입력해야 한다.
- **토스 결제 성공 확인**: 토스 테스트 키(API 개별 연동 키)를 결제 설정에 넣고, 결제창 → 승인 → "셀렉 완료"까지 한 번 직접 확인한다. 로컬에서는 가짜 키로 실패 경로만 확인했다.
- **`PAYMENT_SECRET_KEY`**: 운영 환경에 새 랜덤 값을 설정한다. 이 값을 잃거나 바꾸면 저장된 토스 시크릿 키를 복호화할 수 없어서 작가들이 키를 다시 입력해야 한다.
- **결제 웹훅**: 지금은 결제창에서 돌아올 때(successUrl)만 승인한다. 고객이 인증 후 창을 닫아 돌아오지 못하면 승인이 되지 않고, 인증은 자동으로 만료된다(청구되지 않음). 필요하면 토스 웹훅을 추가한다.
