# 구현 계획

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 프로젝트 세팅 (Next.js, Supabase 로컬), 스키마 마이그레이션, 작가 가입/로그인 | 완료 |
| 2 | 갤러리 생성·목록·설정 (기본 셀렉 장수, 가격, 만료일, 비밀번호) | 완료 |
| 3 | 원본 다중 업로드 (R2 presigned URL), 비동기 미리보기·워터마크 생성 | |
| 4 | 고객 공유 링크와 비밀번호, 모바일 우선 갤러리 뷰 | |
| 5 | 셀렉과 제출 잠금, 핀 댓글 | |
| 6 | 작가 토스 키 연결, 초과분 결제와 승인 검증 | |
| 7 | 보정본 업로드, 파일명 자동 매칭, 고객 다운로드 | |
| 8 | 이메일 알림 (Resend) | |
| 9 | 만료 처리 cron, 배포 | |

## 외부 계정 (해당 단계에서 사용자가 직접 생성)

- Cloudflare R2: 3단계
- 토스페이먼츠 (작가별 키, 개발용 테스트 키): 6단계
- Resend: 8단계
- Supabase 클라우드, Vercel: 9단계
